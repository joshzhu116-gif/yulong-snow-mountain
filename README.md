# 云南丽江 · 玉龙雪山 3D 秘境漫游 (Jade Dragon Snow Mountain 3D Experience)

在线游玩地址 (GitHub Pages)：**https://joshzhu116-gif.github.io/yulong-snow-mountain/**

## 特色玩法
- **雪山徒步漫游**：身着纳西族传统“披星戴月”七星羊皮披肩与百褶裙、手持转经筒，漫步蓝月谷白水台、东巴迎宾牌坊、白桦古松林与纳西水车古村落（篝火打跳、木楞房、东巴祈福经幡）。
- **复古蒸汽观光小火车**：随时登上环绕蓝月谷与古村落的蒸汽观光小火车，支持多节车厢切换、鸣笛与加煤加速。
- **全平台操控支持**：
  - **电脑端**：`W` `A` `S` `D` 或方向键移动，鼠标拖拽旋转 360° 视角，滚轮缩放，`F` 键随时登车/下车。
  - **手机/平板触屏**：左下角虚拟摇杆控制 360° 移动，右侧屏幕单指滑动旋转镜头、双指捏合缩放视角。
